## Learning Philosophy

I believe that understanding AI requires more than using existing libraries and APIs.

My approach is based on a continuous learning cycle:

1. **Understand** — Study the underlying concepts, mathematics, and architectures.
2. **Implement** — Translate theoretical knowledge into working code.
3. **Experiment** — Explore different approaches, architectures, and configurations.
4. **Evaluate** — Analyze results, limitations, and model behavior.
5. **Improve** — Refine implementations and deepen technical understanding.

My long-term goal is to progress from implementing existing techniques to understanding, researching, and developing AI systems.
